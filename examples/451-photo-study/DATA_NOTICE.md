# Photo Provenance And Publication / 原图来源与公开范围

QiushanHuang explicitly requested publication of one previously private photographic set as a README demonstration and example dataset. The selected set is model451: exactly the three files in`photos/` listed in`manifest.json`.

The files are byte-for-byte copies of the supplied photographs. Their numbered labels were already present; the repository does not infer a separate photographer identity from filenames or a private directory. Local source paths and messaging-app identifiers are not published.

The project MIT license covers the software and generated parameter/annotation material. The original photographs are **not assigned an additional reuse license by this notice**: permission to publish this example is recorded separately from photography copyright and any other reuse permission. Contact the maintainer to clarify photograph reuse when needed.
