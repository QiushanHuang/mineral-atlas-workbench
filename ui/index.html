01 / INPUT

参数与证据

预置案例是参考模型；照片编号、矿物名称与晶面指数是三类不同信息。未标定照片不能唯一确定晶面指数。
晶轴、点群与完整参数

A 的列为 a、b、c；四轴时为 a₁、a₂、c，a₃=−a₁−a₂。修改晶系、轴比或点群后会重新检查相容性。

同一参数与算法版本可复现，重复生成使用已校验缓存。
