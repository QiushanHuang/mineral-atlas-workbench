# 多图与不完整形态 · 算法系列 v2

2026-09-26，本地验证版。支持1–24张同一物体的照片，合计64MiB、单张16MiB。无需先选模型或点晶面角点；照片、形态线索和不确定项分别保留。

## 如何使用

工作台顶部选择多张照片，填写“形态线索”。可以写“可能六方柱或六方双锥，端部信息不完整”，也可以写教材中的晶形组合。逐张选择“完整性不确定”“物体完整可见”或“有遮挡或残缺”。默认保持不确定。

只有确实已确认的晶系、**总**面数才填入高级选项；当前看见的面数不等于总面数。不要为了让程序有输入而补全缺失信息。

照片标记残缺，或自动分割疑似不完整时，使用单向、截断的局部轮廓评分，降低权重。它不强迫完整模板贴合遮挡边缘，也不证明不可见部分。文字中的“信息不完整”本身不会把所有照片改为遮挡视角。

## 一套连续算法

|环节|处理|输出与边界|
|---|---|---|
|图像与文件检查|显示方向、大小、损坏文件、物体轮廓|坏文件单独保留，不拖累其余可用图；格式/资源限制仍明确拒绝|
|质量与视角分组|清晰度、轮廓完整性、内容哈希和相似图像分组|重复图不增加组权重；质量指标不是准确率|
|形态解析|日常外形、常见教材名称、OR备选与组合|软提示，不自动把外形等同实物晶系；未知原文保留|
|候选与相机|固定参考形态库、多起点轮廓/长边匹配|输出多个候选；不声称任意库外物体可唯一恢复|
|多图融合|少视角保守加权，多视角抑制大残差|保留逐图贡献与冲突，不保证每加一张都改善|
|证据解析|图像首选、形态影响、删一组稳定性、补拍建议|稳定性不是正确率；用户信息/照片观察/模板假设分别记录|
|几何与导出|闭合、共棱、Euler、指数和模板群检查|只证明候选自洽；保留所有输入照片和不确定项|

形态提示始终是软信息：例如“六方柱或六方双锥”会保留两个假设，而不是强行选择其一。`不是六方柱，是六方双锥`中的否定部分不会被反向用作正证据；当前把否定片段保留为未量化信息。`没有尖端`不再误加“尖端”标签。这是有限词汇解析，不是完整自然语言理解。

重复分组采用字节哈希和物体区域感知哈希，因此“视角组”是计算分组，不等于经过标定的独立相机方向。少于4组时保守使用质量权重；显式或疑似局部视角保持低权重。4组及以上用中位数与MAD限制极端残差。所有候选仍需复核。

## CLI与证据文件

```bash
python3 atlas_cli.py from-photos front.jpg side.jpg back.jpg end.jpg extra.jpg --hints hints.json --out atlas-runs
```

`hints.json`示例（coverage与照片顺序对应）：

```json
{
  "evidence": {
    "morphology": "可能六方柱或六方双锥，端部信息不完整",
    "strength": "tentative",
    "coverage": ["unknown", "complete", "partial", "unknown", "unknown"]
  }
}
```

`strength`可为`tentative`或`likely`；有“可能/或”等不确定表达时仍采用保守强度。物体框`boxes`、已确认`constraints`继续可选。MCP使用`atlas_from_photos`同一参数结构。

每个候选包保存全部照片、逐图状态、形态原文、未解析/否定片段、先验库与程序指纹、依赖版本、相机及融合记录。无法解码的文件保留原始字节（必要时以`.bin`存放）并跳过匹配。原参考15组不被覆盖。

## 验证与复现

41项Python测试覆盖既有核心与新边界；15组/226面JS交互回归通过。重复、模糊、遮挡和未知线索的四模板合成压力试验保留历史记录；本轮追加自动疑似遮挡、否定句、坏文件和24图上限回归。浏览器走通8张照片＋不确定形态→候选→建模，控制台无错误。

```bash
python3 -m unittest discover -s tests -v
python3 scripts/run_js_checks.py
python3 scripts/validate_photo_candidates.py --out evaluation/synthetic
python3 scripts/validate_photo_evidence.py --renders evaluation/synthetic --out evaluation/stress
python3 scripts/benchmark_evidence_series.py --photos ../reconstruction/photos.json --photo-root ../reconstruction --out evaluation/evidence-benchmark
```

真实照片与原始逐图结果只存本地evaluation，不进入通用包；公开汇总见[verification/photo-evidence-series.json](../verification/photo-evidence-series.json)。仅调整融合规则时可使用`--reuse-fit-records`复用未变的逐图结果；改了分割或匹配则必须重新计算相关输入。

仍未解决：库外新形态、精确深度恢复、残缺实物的唯一补全、物理晶系/晶面指数自动测定。未知形态描述和否定片段会保留，但不保证理解任意表述。没有新GitHub发布或远端CI运行。
