# 照片判读、编号和配准

## 先建立证据表

每张图保存源文件名/哈希、宽高、显示方向与EXIF、图像中可读面号、可见面形、共棱关系、遮挡和不确定部分。文字、轮廓、颜色分开记录：油漆边界、裂纹与磨损不自动算晶棱。

先看能辨别轴与两端的代表图，再以另外的侧面/端面验证。已经足以约束一个局部修改时，不反复重读整套图片。面数约束已给定就作为硬检查，但不能靠凑够面数验收。

编号保留照片的原值。通过共棱和端部方向匹配，不按“数字应顺时针连续”假设分配。看不到的编号可暂配，但必须在表格和HTML一致标注。不同照片的环向冲突可能来自误读、错误面对应、镜像、轴向或构形；先查原因，不静默交换两个标签。

## 原始像素标注

工作台直接导入PNG/JPEG，在同一原图显示方向下点击所选晶面的角点；沿边界循序点击。另标整体外轮廓，不把手指边缘纳入。可读编号的面中心仅作低权重朝向约束，因为文字不一定写在几何中心。

标注JSON示例：

```json
{
  "schema_version":1,
  "face_id":"F01",
  "image_size":[960,1280],
  "mode":"cyclic",
  "points":[[157,666],[363,576],[570,556],[391,648]],
  "silhouette":[[157,666],[363,576],[570,556],[709,716],[585,802],[355,808]],
  "face_centers":{"F02":[374,735],"F03":[565,661]},
  "loss":"soft_l1",
  "mirror":"not_assumed"
}
```

mode=cyclic枚举角点循环对应；不意味着照片已标定。mode=correspondences时提供与points一一对应的`vertex_ids`，可跨面标注；`face_id`用于至少一张明确可见面的正反判据。

需要独立验证时另给`holdout:[{"vertex_id":7,"xy":[x,y]}]`。这些点不能同时参与拟合。图像分辨率或EXIF方向不同，必须转换标注或重新点选，不能直接套旧像素。

## 拟合与消歧

默认相机距离为8个模型半径，拟合旋转、统一缩放、平移。它是明确的近似透视，不是假装已知焦距。确定性几何初值先做粗拟合，再精化少量最佳解；轮廓采样提前缓存，稳健损失用于降低少量坏点影响。

输出分别看：原始像素角点RMSE、图像对角线归一误差、独立留出误差、竞争解、候选面是否在背面。不能把仅三个点的完美拟合当作整体复原。没有独立点时如实显示null。

发现多解时，优先增加一个不共面的已知角点、端面方向或另一张照片。若主要偏差来自外形，应修正面距或候选晶形后重新检查拓扑，而不是不断增加随机相机起点。面型、c/a和相机距离可能耦合；无校准不宣称唯一解。

镜像是离散假设，必须有来源并显式比较。当前工具不自动镜像照片；无法可靠对应的照片只显示原图或并列候选，不给确定编号叠加。

## 停止条件

当前请求涉及的面形、共棱、轴向和编号均有可追溯状态；数值校验通过；代表视角已查看，剩余偏差/遮挡/未知已说明，即可交付。不能把未知消除作为无限加拟合轮次的理由；需要决定性新证据时指出具体缺项。
