# 在线助手与本地视觉分析流程

用于实际照片判读、形态候选或建模核对。简单术语/格式问题直接回答，不套完整流程。在线是执行环境，不是更高证据等级；在当前对话分析附件，不等于授权把原图上传到另一服务。

## 先看当前能做什么

重用本任务已有照片、模型和记录。能读图就做逐图观察；只能读文字就明确来源，不假装重新查看图片。当前有`atlas_from_photos`时可生成候选；没有该工具、相关CLI或依赖时继续人工证据分析，不编造拟合/OCR结果。必要时读[工具说明](tools.md)，不要为了开始一次照片分析扫描所有环境或安装模型。

## 证据先行，再建候选

1. **照片身份与可用性**：给照片稳定ID；记录实际可读的方向、尺寸和原始编号。标记重复/裁剪、模糊、遮挡、破损及无法解码的文件。只有执行了相应检查才写哈希、EXIF或测量值；重复图不算独立支持。
2. **拆开四类信息**：照片直接观察、用户提供的信息、模型/模板假设、未知。每个重要判断指向照片ID及可见部位；看不清的负号、上划线、面号保留原文和歧义。文字、阴影、磨损与真实棱分开。
3. **保留多个解释**：区分“可能A或B”和“A与B组合”。否定不能作为正证据；不理解的片段保留，不静默归类。只有明确确认的晶系和总面数是硬约束；可见面数、不确定形态和残缺描述不能冒充完整参数。
4. **跨图寻找反证**：每个候选分别列出支持、冲突、未覆盖部位和依赖先验。不要先选模板再替它解释所有照片。允许库外/全部候选不足。不要为降低误差偷偷改面号、镜像或强制两端等价。
5. **残缺只约束可见部分**：遮挡、破损、裁剪边界不是天然晶面边界；局部吻合不能验收完整外形。提出最有区分力的补充观察，例如完整另一端、不同侧面、同一棱两侧，而非机械索要更多相似照片。
6. **构形与晶体学分层检查**：需要生成模型时再进入[阶段提示词](prompts.md)的构形步骤。面形、真实共棱、法线/面距、闭合性、参考指数、点群兼容分别核对。数字/F编号/指数不互换；几何群与实物群不混用。同平面上画线不能恢复真实棱。
7. **验收与不确定性**：几何自洽、照片拟合、独立对照分开。低残差、稳定排名、面数正确均不能单独证明外形正确；更多视角也可能加入坏证据。调整几何后重算受影响相机和指标，误差变大如实记录。无独立验证时不宣称精度提升。

## 建议输出

按用户请求裁剪，不必每次长篇报告：

- **观察**：照片ID、可见部位、原始文字/面号、证据来源。
- **候选**：可能形态、支持与冲突、模板/轴比/隐藏面的假设。
- **未知**：未覆盖部位、否定/备选原文、需要的最少新证据。
- **结论层级**：可直接观察 / 待核对候选 / 计算自洽 / 经独立验证。不能跳级。
- **下一步**：最能区分候选的一个动作；动作是否需要额外授权依当前任务，不由本流程扩权。

如调用要求JSON的视觉模型，使用[可复制视觉提示词](visual-analysis-prompt.txt)。在线助手也可直接应用上述流程；无需把全部历史案例塞进每次提示。

## 经验如何进入后续算法

保存失败类型与证据，而不是把一次失败变成所有任务的硬规则。至少记录输入/策略版本、发生在哪一层、是否涉及重复或局部视角、提示的确定性、实际操作及结果、未解决限制。复用有效基线；只对变动环节做必要回归。评价图像算法用真实图像与独立标注；评价提示词先用固定情景，再在授权且有代表性的图像集上检验。文字情景通过不能写成在线识别准确率提高。

历史例子只解释风险：611的外形修正与旧照片残差改善不是一回事；6512出现过稳定但错误的首选；三角外观不唯一决定晶系。不要把这些旧案例的标签当作新照片的答案。

本流程不提供远程服务凭据，不自动外发私人照片，也不授权提交、发布、安装、覆盖既有模型或更新科学记录。
